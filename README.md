## Requirements

- **Python version:** `< 3.12` (some dependencies are not yet compatible with 3.12 or later)

### Required Packages

Install the following dependencies using `pip`:

```bash
pip install fastapi
pip install "uvicorn[standard]"
pip install google-generativeai
pip install pandas
pip install torch
pip install joblib
pip install numpy
pip install scikit-learn
pip install transformers
pip install camel-tools
pip install nltk
